# Tutorials

*Learning-oriented*: step-by-step lessons that take a newcomer from zero to a working
result, building confidence rather than explaining every option. Written for someone
following along, not looking something up.

Add tutorials here as the project becomes usable, e.g.:

- `getting-started.md` — set up a local dev environment and run the app for the first
  time.
- `your-first-location-share.md` — walk through adding a friend and sharing location.

See the [Diátaxis tutorials guide](https://diataxis.fr/tutorials/) for how to write
good tutorials (concrete steps, guaranteed outcome, minimal explanation).
